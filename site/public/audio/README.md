# Áudio dos easter eggs

## Hino (easter egg da bandeira tricolor)

A brincadeira da bandeira toca, por padrão, uma **fanfarra sintetizada** (gerada
em código, sem arquivos). Se você quiser que toque o **hino de verdade**, basta
colocar aqui um arquivo chamado exatamente:

```
spfc-anthem.mp3
```

Ou seja: `site/public/audio/spfc-anthem.mp3`.

Quando esse arquivo existir, ele toca no lugar da fanfarra automaticamente.
Se não existir, cai na fanfarra — então o site funciona dos dois jeitos.

> Use um arquivo que você tenha direito de usar (o repositório não inclui
> nenhum áudio com direitos autorais).

O drone sinistro da seção Ominiosos é 100% sintetizado e não precisa de arquivo.
